# BLM Protests & Voter Turnout

> Estimating the causal effect of Black Lives Matter protests on voter turnout using instrumental variables and spatial regression — Georgia proof of concept.

## Overview

Did the 2020 BLM protest wave causally increase voter turnout? This project addresses that question at the census block group level in Georgia using a **rainfall instrumental variables** design: protest locations are endogenous (protests clustered in high-turnout areas), but rainfall on protest days is plausibly exogenous — it deterred attendance without directly affecting November turnout.

## Methods

| Step | Approach | Target |
|---|---|---|
| Data ingest | Census API, raw voter file | `GA_data_raw`, `GA_shapefile` |
| Cleaning | GEOID parsing, shapefile merge | `GA_sf`, `pred_clean`, `GA_iv` |
| Spatial diagnostics | Moran's I, LM tests | `ga_weights`, `moran_results`, `lm_tests` |
| Modeling | OLS → first stage → 2SLS → Spatial Error | `ols_m3`, `first_stage`, `iv_2sls`, `sp_error` |

The instrument is **relative rainfall** (inches) during the protest study period. The first-stage model predicts log distance from a protest; the second stage estimates the effect of that instrumented distance on 2020 general election turnout share.

## Reproduce

```r
# 1. Clone the repo and restore packages
renv::restore()

# 2. Add your Census API key
# Copy .Renviron.example → .Renviron, fill in your key, restart R

# 3. Run the full pipeline (only re-runs targets that have changed)
targets::tar_make()

# 4. Visualize the dependency graph
targets::tar_visnetwork()

# 5. Preview the Shiny app
shiny::runApp("shiny/")
```

Or from the terminal:
```bash
Rscript -e "targets::tar_make()"
```

The Quarto site is built automatically as the final step via `tar_quarto(site)`.

## Data Sources

- **Voter file turnout:** L2 Political (licensed)
- **BLM protest locations:** [Count Love](https://countlove.org)
- **Rainfall:** NOAA / PRISM daily precipitation
- **Demographics & shapefiles:** U.S. Census Bureau ACS 2019, via `tidycensus` / `tigris`
